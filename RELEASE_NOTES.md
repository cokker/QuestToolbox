Первая предварительная версия Quest Toolbox для Windows 10/11 x64.

## Скачать

Скачайте **QuestToolbox-Windows-x64.zip**, распакуйте весь архив и запустите **QuestToolbox.exe**. Оставьте вложенные папки рядом с EXE. Python устанавливать не нужно.

В «Настройках» скачайте официальный ADB либо выберите установленный adb.exe. Включите режим разработчика и подтвердите USB-отладку внутри Quest.

## Возможности

USB/Wi-Fi ADB, несколько шлемов, APK и split APK, приложения и избранное, файлы и записи, параметры дисплея с откатом, профили, scrcpy, logcat, диагностические отчёты, RU/EN и две темы.

## Проверки перед публикацией

Релиз создаётся только после успешных тестов на Windows, сборки PyInstaller и запуска собранного EXE. Проверяется открытие и отрисовка всех девяти разделов. Скриншоты и JSON-отчёт сохраняются в артефакте Windows-startup-proof в GitHub Actions.

## Исправления перед первым релизом

- Проверка обновлений учитывает Preview-релизы; GitHub /releases/latest их не показывает.
- Остановка logcat дожидается завершения процесса и не оставляет активный процесс при закрытии.
- Недоступная папка показывает ошибку, а не пустой список.
- Пути ADB/scrcpy сохраняются только после проверки обоих полей.
- Добавлены проверки прокрутки колесом, сохранения позиции при смене вкладок и отсутствия изменения прозрачности окна.

**Физические Quest в этой сборочной среде недоступны.** Команды реализованы по документации Android/Meta, но совместимость с каждой прошивкой требует проверки на устройстве. Это Preview, не заявление о тестировании всех моделей. Quest Pro: максимум 90 Гц в документированном списке; запись свойства не равна измерению фактического FPS.
